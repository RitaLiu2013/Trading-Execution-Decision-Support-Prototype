# Knowledge-note sources

The RAG notes are deliberately short, educational summaries rather than a production trading methodology.

Primary references:

- CFA Institute, **Trading Costs and Electronic Markets**: execution costs, implementation shortfall, VWAP transaction-cost estimates, market impact and unfilled-trade costs.  
  https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/trading-costs-and-electronic-markets
- Investor.gov, **Understanding Order Types – Investor Bulletin**: execution price is not guaranteed and parts of a large order can execute at different prices when liquidity is limited.  
  https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins-14
- Investor.gov, **Executing an Order**: execution venue and market conditions can affect transaction cost and execution price.  
  https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/executing-order

These sources support the high-level concepts used in the prototype. The repository does **not** claim to implement a production transaction-cost-analysis framework.
